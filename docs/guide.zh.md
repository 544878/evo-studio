# 中文使用指南

Evo Studio 把多人或多个程序协作做一件事的过程记在本机。以制作片头为例，总经理建单，制作岗交出 SVG，审校岗检查该版本，归档岗才可以开始。README 中的命令使用合成素材，复制到一个空的数据目录即可按顺序操作。

| 想做什么 | 入口 |
| --- | --- |
| 看谁在等回复、哪份作品待审 | attention 或本地网页驾驶舱 |
| 找回交付时的原件 | artifact 加文件摘要 |
| 让自己的程序接单 | worker 通过标准输入交付任务，通过标准输出接收作品 |
| 留下个人成长记录 | remember 写记录，consolidate 整理，promote-memory 确认 |
| 改进岗位流程 | 从退回记录提出一条规则，绑定回归报告，由本机操作者确认启用 |
| 对外展示 | 从已验收工单另写公开文案，按用途确认，再导出 |

角色名表示本机操作者当前执行的职责。多个互不信任的用户需要各自的系统权限与数据目录。实际模型服务和远端发布由接入方选择。

网页看板供单机使用，同机进程可以访问。页面只显示工单编号、依赖、状态和待审数量。私人正文由所有者在本机通过 events 命令查看。
