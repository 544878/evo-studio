## 工程交接
```flow LR
派单 -> 检查依赖 -> 执行器 -> 保存产物 -> 独立角色复核
独立角色复核 -> 退回修改
退回修改 -> 执行器
独立角色复核 -> 完成
```

## 岗位与成长
```flow LR
返工记录 -> 单条规则提案 -> 人工核对回归报告 -> 启用或回滚
个人记录 -> 整理候选 -> 人工确认 -> 本地知识库
```

## 展示出口
```flow LR
已复核工单 -> 选择公开文字 -> 检查常见敏感格式 -> 确认内容和用途 -> 导出
```
