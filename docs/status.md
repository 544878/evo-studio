# Verification and release scope / 核验与发布范围

TypeScript static checking passed on Node 24.22.3. An end-to-end scenario is included. Runtime testing was deferred. No timing, crash-recovery, privacy guarantee or real-world deployment result is claimed.

已完成静态类型检查。端到端脚本覆盖任务依赖、产物交接、角色复核和展示授权。按要求暂缓运行，真实岗位联调和多日成长记录尚待验证。

| Goal | In this preview | Acceptance work remaining |
| --- | --- | --- |
| Local control | Transactional SQLite events and blobs, revision checks, dependency and scope checks, handback and rework | Abrupt process termination and concurrent workloads |
| Executors | Local subprocess adapter and synthetic SVG worker | Real model and production role integration, isolated identities and sandbox |
| Attention | Local read-only web desk, attention list and graph | Live updates, owner questions and operational alerts |
| Evolution | Evidence-linked incremental proposals, stale-base checks, report checks and undo | Independent replay, observation period, upstream three-way upgrade and three real roles |
| Growth | Personal notes, consolidation, approval, Markdown vault and weekly journal | Multi-day observation, fact reconciliation and tone evaluation |
| External surfaces | Source intake, content-bound approval, local delivery receipts and exports | Remote provider integration and crash-recovery trials |

The data format is a pre-release format. Keep backups of the private state directory while the service is stopped. Public source uses synthetic roles and examples.
